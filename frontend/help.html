Help Center

Use the system with confidence.

This page is for actual actions and edge cases, not the same intro text as the home page. Use it when you need to post, claim, verify, or contact support.

Report a Lost Item Report a Found Item Contact Support

What to do first

1

Decide the correct path

If you lost something, open the lost report. If you found something, open the found report. That keeps the feed accurate and avoids duplicate posting.

2

Add proof-quality details

Use color, brand, size, location, and a clear photo if possible. The best reports are specific enough that real owners can recognize the item.

3

Claim or match carefully

Open item details, check the posted date and description, then contact the poster or submit a claim only after you are confident it is yours.

When you are stuck

  • The item card is not opening: refresh the page or check if the backend is running.
  • You cannot post: make sure you are logged in first.
  • Your photo is blurry: re-upload a clearer image with good lighting.
  • Password reset not arriving: check whether SMTP is configured on the server.
Important: never share your password or private verification code with another student.

Status meaning

Pending The item is waiting for review or a response.
Available The item is active and can still be claimed or matched.
Resolved / Claimed The item has already been successfully matched.
Archived The item is older and may no longer be active on the main feed.

Safety and verification

A

Meet in public

Use a visible campus area, not a private room or isolated place.

B

Ask for item-specific proof

Use details only the owner would know, such as a sticker, scratch, name tag, or content inside the bag.

C

Escalate suspicious claims

If someone is acting suspiciously, contact campus security or the admin immediately.
